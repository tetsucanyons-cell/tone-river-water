# 利根川 水位・ダム速報 Webアプリケーション (みなかみラフティング向け)

群馬県みなかみ町の利根川水系におけるラフティング・カヤック等の水上アクティビティ向けに開発された、リアルタイム水位・ダム放流・雨量速報アプリです。

国土交通省「川の防災情報」から10分ごとに更新される実測データを取得し、事実ベースの時系列推移をスマートフォン（iPhone等）やPCで瞬時に確認できます。

---

## 🌟 主な機能と特徴

1. **メイン画面（10分刻み実績タイムライン）**:
   - 最重要地点である**「湯原水位計」**と**「藤原ダム」**の現在コンディションをトップに特大表示
   - **湯原の水位（m）**、**藤原ダムの放流量（m³/s）**、**藤原ダムの流入量（m³/s）**、**湯原の10分雨量（mm）**、**貯水率（%）**を同一タイミング（10分刻み）で並べた一覧テーブル（スクロールして過去50件＝約8時間分の事実推移を確認可能）
   - 水位の増減傾向（増水▲ / 減水▼ / 安定→）や10分・1時間前比の変化量表示

2. **タブ切り替え機能**:
   - **【10分推移・メイン】**: 湯原水位 × 藤原ダム放流 × 雨量の統合タイムライン
   - **【水位一覧】**: 4大水位計（湯原、月夜野橋、小袖橋/小出、湯宿）の詳細カード
   - **【ダム諸量】**: 上流4ダム（藤原、奈良俣、矢木沢、相俣）の流入量・放流量・貯水率一覧
   - **【推移グラフ】**: 直近8時間の二軸相関グラフ（湯原水位 × 藤原放流）および比較チャート（Chart.js）
   - **【天気・雨量】**: みなかみ町（湯原・水上）の現在気象・1時間ごと天気予報・周辺観測所雨量

3. **リアルタイム自動更新 & PWA対応**:
   - アプリを開いた瞬間に最新データを即座に取得
   - 10分サイクルでの自動リフレッシュ（カウントダウンタイマー付き）
   - 手動更新ボタン搭載
   - **iPhoneのSafariで「ホーム画面に追加」することで、ネイティブアプリのように全画面で起動可能**

---

## 🚀 起動方法

### Windowsの場合（最も簡単）
フォルダ内の `start.bat` をダブルクリックするだけでサーバーが起動します。

### コマンドラインから起動する場合
```bash
python server.py
```

起動すると、以下のようにアクセス用URLが表示されます：
```text
============================================================
  利根川水系 水位・ダム速報 アプリケーション
============================================================
  [PC ブラウザ]   http://localhost:8080
  [iPhone / スマホ] http://192.168.0.xxx:8080
  ※iPhoneと同じWi-Fiに接続してSafariで上記URLを開いてください
  ※Safariの「共有」ボタンから「ホーム画面に追加」でアプリ化できます
============================================================
```

---

## 📱 iPhoneでの使い方（アプリ化手順）

1. PCと同じWi-FiネットワークにiPhoneを接続します。
2. iPhoneの **Safari** を開き、画面に表示されたスマホ用URL（例: `http://192.168.0.xxx:8080`）にアクセスします。
3. 画面下部の中央にある **「共有ボタン（四角から上矢印が出ているアイコン）」** をタップします。
4. メニューから **「ホーム画面に追加」** を選択し、右上の「追加」をタップします。
5. ホーム画面に専用アプリアイコン（利根川水位）が追加され、タップすると全画面のWebアプリとしていつでも素早く確認できます。

## 📁 構成ファイル

- `server.py`: バックエンドAPIサーバー（川の防災情報・気象データの非同期取得 & キャッシュ & 静的配信）
- `start.bat`: Windows用ワンクリック起動スクリプト
- `public/`:
  - `index.html`: アプリケーション画面（PWA対応）
  - `css/style.css`: iOS最適化・ダークテーマ・高視認性スタイルシート
  - `js/app.js`: リアルタイムフェッチ・タイムライン生成・Chart.jsグラフ描画
  - `manifest.json`: PWAマニフェストファイル
  - `sw.js`: Service Worker（キャッシュ管理）
  - `icons/`: アプリアイコン画像
